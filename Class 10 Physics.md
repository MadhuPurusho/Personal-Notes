### 1. Light – Reflection and Refraction

- **Mirror Formula:** $\frac{1}{f} = \frac{1}{v} + \frac{1}{u}$ _(where $f$ = focal length, $v$ = image distance, $u$ = object distance)_
    
- **Magnification for Mirrors:** $m = -\frac{v}{u} = \frac{h'}{h}$ _(where $h'$ = height of image, $h$ = height of object)_
    
- **Refractive Index ($n$):** $n = \frac{c}{v}$ _(where $c$ = speed of light in vacuum, $v$ = speed of light in medium)_
    
- **Lens Formula:** $\frac{1}{f} = \frac{1}{v} - \frac{1}{u}$
    
- **Magnification for Lenses:** $m = \frac{v}{u} = \frac{h'}{h}$
    
- **Power of a Lens ($P$):** $P = \frac{1}{f}$ _(where $f$ must be in metres; unit is Dioptre, D)_
    

### 2. Electricity

- **Electric Current ($I$):** $I = \frac{Q}{t}$ _(where $Q$ = charge, $t$ = time)_
    
- **Quantisation of Charge:** $Q = ne$ _(where $n$ = number of electrons, $e$ = charge of an electron $1.6 \times 10^{-19}\text{ C}$)_
    
- **Potential Difference ($V$):** $V = \frac{W}{Q}$ _(where $W$ = work done)_
    
- **Ohm's Law:** $V = IR$ _(where $R$ = resistance)_
    
- **Resistance Factors:** $R = \rho \frac{l}{A}$ _(where $\rho$ = resistivity, $l$ = length, $A$ = cross-sectional area)_
    
- **Resistors in Series:** $R_s = R_1 + R_2 + R_3 + \dots$
    
- **Resistors in Parallel:** $\frac{1}{R_p} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} + \dots$
    
- **Electric Power ($P$):** $P = VI = I^2R = \frac{V^2}{R}$
    
- **Heat Dissipated / Electrical Energy ($H$):** $H = VIt = I^2Rt = \frac{V^2}{R}t$
