# Division of Powers

Division of legislative powers in India under 7th Schedule:

```
┌────────────────────────────────────────────────┐
│                DIVISION OF POWERS              │
├──────────────┬──────────────┬──────────────────┤
│ Union List   │ State List   │ Concurrent List  │
│ Centre only  │ State only   │ Both Centre+State│
│ 100 subjects │ 61 subjects  │ 52 subjects      │
│ defence,     │ police,      │ education,       │
│ foreign      │ trade,       │ forests,         │
│ affairs,     │ agriculture, │ marriage,        │
│ banking,     │ irrigation   │ adoption         │
│ currency     │              │                  │
└──────────────┴──────────────┴──────────────────┘
         + Residuary Subjects (new matters) -> Union Govt decides
```

- **Union List:** Centre only. Defence, foreign affairs, banking, currency, railways.
- **State List:** State and local only. Police, trade, agriculture, irrigation.
- **Concurrent List:** Both Centre and State. Education, forests, marriage, adoption. In case of conflict, Union law prevails.
- **Residuary Subjects:** New matters like computer software, e-commerce. Union decides.
- **Constitutional Protection:** Power-sharing cannot be changed unilaterally. Needs 2/3 majority in Parliament + approval of states.
- **Umpire:** Supreme Court settles Centre-State disputes.
- **Unequal Units:** Union Territories like Delhi, Chandigarh, Ladakh have very little power. Central Govt administers them directly.
